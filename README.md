# Girardi Hogar — demo

Demo del sistema de venta en cuotas y cobranza puerta a puerta de Girardi Hogar.

**Todos los datos son inventados** y viven en el navegador: lo que se cargue acá
no se guarda en ningún lado y al recargar la página vuelve a empezar. No está
conectada al sistema real.

Abrir: https://belomateo.github.io/girardi-demo/
